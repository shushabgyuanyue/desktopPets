# 蚁群桌面宠物

Windows 桌面上的透明蚁群宠物。回收站图标是巢穴；真实文件、文件夹和应用快捷方式的桌面图标是障碍物。移动食物或桌面图标后，蚂蚁在当前位置继续探索，只有被新障碍挡住的个体会调整路线。切换到其他应用时画面隐藏，蚁群仍在后台运动；回到桌面会显示最新状态。

蚂蚁探索时会留下短暂的信息素，青色表示探索，橙色表示找到食物后的返巢路线；面板可以切换显示。探索信息素会逐渐挥发，也会降低蚂蚁重复踏入同一区域的倾向。每只侦察蚁保留独立的探索朝向，依据局部障碍和信息素缓慢调整，在屏幕边缘转向内部；探索评分不再持续奖励远离巢穴。空手侦察一段时间后，蚂蚁会沿自己走过的路返巢，在失败路线加深探索标记，再换一个朝向重新出发；大桌面的侦察行程会相应变长。在信息素方向接近的路口，个别蚂蚁会短暂停下嗅探；走进死路会先转头再退回。只有接近食物后才会感知它；首次闻到食物的蚂蚁会停下嗅探，附近同伴会错峰张望，最先到达的两只会在食物旁短暂勘察。到达食物会停留切割约 0.75～1.2 秒，切完才拾取一片。携食后蚂蚁会放慢脚步，以巢穴方向作局部判断，边走边强化实际走通的路线；之后的蚂蚁更容易沿有效信息素找到食物。移动图标截断已有路线或移动文件食物时，附近受影响的蚂蚁会短暂停下重新探路。新放置的食物即使落在已走过的区域，蚂蚁闻到后仍可回访。程序不提前计算路线，也不会让蚂蚁沿一条固定路线循环播放。

算法属于使用 ACO 概率转移、信息素挥发与路线质量强化的连续局部觅食仿真；不保证找到全局最短路径。探索/排斥素是额外的分散机制，并非标准蚁群优化算法的必备组成。详见 [2026-11-06 算法审计](diagnostics/algorithm-audit-2026-11-06.md)。

蚂蚁采用灰绿色平涂、粗黑轮廓、夸张白眼与细小瞳孔的荒诞科幻卡通造型，保留三段身体、六条腿和不对称触角。桌宠运行时，回收站图像替换为动态酸绿旋涡传送门，原生名称和操作保留；蚂蚁进出会拉伸膜面、带出黏液与扩散水波，详见 [传送门美术设计](docs/portal-art.md)。八相行走步态跟随实际位移；嗅探和勘察时后腿站稳，头部与触角独立探查；切割分为就位、三次咬合和收势。携食转身更缓，部分迎面相遇的空手蚂蚁会短暂摆触角回应。演出细节见 [动作设计](docs/performance-design.md)。所选文件的图标图像由馒头覆盖，原生文件名保留在下方；蚂蚁可从馒头四周可达的位置取食，搬运文件片时嘴边会含小馒头。返巢后，小馒头会在回收站入口缩小并落入图标，入口会扬起少量尘土，完成这段动作后才计入进度。

蚂蚁由高 DPI Canvas 精灵图集绘制。切换到其他应用时暂停绘制并释放画布缓存，蚁群仍在后台按真实时间模拟；返回桌面后继续显示当前状态。若手绘渲染不可用，会退回简化二维绘制。桌面图标与前台窗口状态由轻量本机探针读取，编译或运行失败时会回退到 PowerShell 探针。

文件馒头会随切下的片段依次显示为完整、3/4、1/2、1/4；探索与食物信息素分别用荧光青色和橙黄色显示。首次将文件拖入面板时会出现一次提示，后续只保留悬停高亮。文件成功移入回收站后，其进度会从面板消失。

## 运行

```powershell
npm install
npm start
```

`npm start` 会先构建本地手绘渲染脚本。也可以双击桌面上的“蚁群”快捷方式启动；快捷方式使用项目目录中已构建的脚本。

启动后右上角是控制浮层。点击“放食物”，再在真实桌面的空白处点击即可放置。可拖动食物改变位置，拖动原生桌面图标改变障碍位置。

“添加文件食物”是同一个点击和拖入入口，可多选，也可以把桌面文件拖入控制面板。只接受用户桌面或公共桌面目录中的直接文件，不能选择其他目录或桌面子文件夹内的文件。确认后每个文件成为独立食物源，共用一群蚂蚁；普通食物也可同时存在。移动文件图标时取食位置跟随移动，已搬运的进度不会重置。若图标暂时消失或四周不可达，该文件会暂停新拾取，已在途切片继续，图标恢复后继续。大文件自动使用较大的随机片段，每个文件总片数不超过约 512 片；小文件按比例分成两片，每片都小于源文件。文件至少需要 2 字节。原文件在搬运期间保持不变；全部送达时，程序逐个核对桌面位置与文件身份，并逐个询问是否移入 Windows 回收站。最终确认默认保留文件；随时可以单独取消，校验失败不会主动删除原文件。

快捷键：`Ctrl+Alt+F` 放置食物，`Ctrl+Alt+A` 显示图标障碍边界。关闭控制浮层的叉号会退出程序。

## 官网与下载

官网静态页面位于 [`website/`](website/)，下载入口指向 GitHub Releases。仓库地址是 [shushabgyuanyue/desktopPets](https://github.com/shushabgyuanyue/desktopPets)。

在 Vercel 中导入这个仓库，把 Root Directory 设为 `website`，Framework Preset 选择 `Other`，即可部署官网。仓库根目录的 `vercel.json` 也支持直接从根目录部署并使用 `website` 作为输出目录。

Windows 免安装版通过 `npm run dist:win:portable` 生成，安装版通过 `npm run dist:win` 生成。两种文件都可以上传到 GitHub Release；安装版额外配合 `latest.yml` 提供应用内更新。

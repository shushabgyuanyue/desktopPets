# 荒诞科幻卡通蚁群与黏液传送门

美术方向参考《瑞克和莫迪》的二维科幻卡通语言：粗黑线、灰绿色平涂、大小不一的浅白眼睛和不对称的表情。新版本用圆头、瞳孔高光、少量腮红增加亲和力，保持三段身体、六条腿、双触角。两只原创主题客串分别是护目镜科学家与紫披风探险家，非官方授权联名素材。

桌宠运行时，回收站图像的位置用酸绿色旋涡替换，原生文件名、鼠标命中范围和回收站功能保留。背景来自图标位置对应的壁纸补片，门的边缘起伏和旋涡缓慢运动，不覆盖原生名称。

- 出门：按真实出巢时机，从门心渐显，穿过膜面恢复体型；约 0.55 秒完成。
- 入门：携食抵达巢穴后，朝门心缩小、轻微纵向拉伸、透明消失；仍在原有约 0.48 秒入巢完成后才计入送达。
- 黏连：门心与蚂蚁之间用两条贝塞尔曲线形成薄膜，越拉长越细，随穿越进度收束消散。
- 涟漪：穿越时在门心产生两层不同相位的绿色波纹，离开后自行衰减。
- 自主波纹：四层错相椭圆波从中心扩散，约 3.1 秒一轮；即使没有蚂蚁穿越也持续变化，暂停时一起停下。
- 蚂蚁和携带的小馒头共享穿门位置与缩放计算，避免物体先消失或留在原地。

传送门绘制采用小区域二维路径，不使用全屏模糊、着色器或额外透明窗口。蚂蚁继续复用缓存图集。旋涡时间跟随模拟时间，暂停时停止；桌面隐藏时画布停止提交。

## 星际点心与轻量演出

- 食物改为焦糖色旋纹顶、绿色夹心的星际泡芙，沿用原生图标位置、文件名和四档消耗状态。普通投食、搬运碎块和入门交付共用同一个矢量绘制函数。
- 前足抬起托住食物，其余四足交替行走。入门使用相同食物轮廓与托举偏移，随膜面缩放；只在真实送达后增加进度。
- 两只特别装扮复用普通蚂蚁图集，只叠加少量路径；按可见演出时间分幕，在出门阶段决定是否穿装扮，不会在搬运途中切换。
- 每只蚂蚁有错开的短眨眼；披风随步伐摆动，出门带甩落黏液。继续保留切割三段动作、嗅探、发现食物转头、近距离触角招呼和负重缓冲。
- 125% 缩放时图集从 576 KiB 增至 648 KiB。增加一行入门托举姿势，未增加整套换装图集、全屏粒子层或持续 CSS 动画。

## 前台切换

移除主进程统一 600ms 隐藏延迟。原生探针在独立消息线程上监听 `EVENT_SYSTEM_FOREGROUND`，切换应用时立即推送分类变化；250ms 查询保留为故障/拖动恢复兜底。输出加锁去重，读取图标不阻塞事件监听，标准输入关闭后解除钩子并结束线程。桌面拖动弹窗识别沿用；隐藏后模拟继续，画布停止提交。

实测双进程前台窗口烟测：无连续 focus 查询也收到 desktop → other → desktop；other 通知约 272ms（包含启动测试应用），恢复通知 15ms，探针正常退出。该测试验证事件路径，不代表所有设备的合成器都能做到零帧残留。

## 体验自查

设计参考：荒诞科幻二维卡通与液态膜面。

移动端检查：桌面尺寸与窄窗口渲染烟测通过，图标名区域保持透明，不增加面板布局。

文案/样式复用：保留现有面板、食物和操作方式；荧光绿集中在巢穴和穿越效果。

发现的问题：原回收站遮罩会切掉门内蚂蚁；出巢只有平地出现；独立入巢坐标会让食物和蚂蚁错位。

已修复：传送门区域允许穿门精灵显示，共享穿越姿态，独立校验回收站移动后的背景和坐标更新。

本轮设计参考：粗墨线二维科幻卡通、酸绿传送膜和紫色披风点缀。

本轮移动端检查：桌面程序按 390px 窄视口验证面板边界，复用现有收纳方式，无横向溢出。

本轮文案/样式复用：保留面板结构、上传/拖入单入口和文件安全文案，统一墨线与色板；背景半透明并保留模糊，深色字在浅色底上清晰。

本轮发现的问题与修复：切换应用延迟隐藏；携食像含在嘴里；门户只有穿越反应；食物与入门切片造型不同。分别以原生事件通知、前足托举、自主涟漪和共用绘制函数修复。外部合成器时序仍无法保证绝对零延迟。

本轮验证：62 项单元测试通过；手绘渲染、暂停与图集复用、门户集成、入门交付、隐藏继续模拟和窄面板烟测通过；原生探针编译、前台事件推送与退出检查通过。测试使用虚拟文件任务，没有回收用户文件。预览：`space-pet-panel.png`、`space-pet-art.png`。

验证：算法与文件安全 62 项测试通过；传送门集成测试验证入/出门两端透明度、旋涡随时间改变、原生标签区域未绘制、门内精灵可见、移动回收站更新补片；手绘渲染、文件图标联动、可见性与暂停动作烟测通过。

# 蚁群：有性格的微小动作

这一版保留炭黑简笔画造型，用触角、头部、脚步与身体的先后顺序表达状态。动作幅度以桌面实际尺寸为准，放大图只是检查细节。算法决定走向与行为发生的时机，绘制表现动作的节奏。

| 场景 | 已实现演出 | 节奏 |
|---|---|---|
| 探索行走 | 八相步态，脚步随位移变化，身体有极小幅度的重心转换 | 个体步态错开，停止位移就收住脚步 |
| 闻到食物 | 触角先响应，再朝实际感知的食物方向转身 | 动作前 18% 留给触角，随后逐步转向 |
| 附近同伴听到动静 | 朝发现者方向短暂回应，继续自己的探索 | 延续个体错峰停顿，不全群齐转 |
| 岔路嗅探／食物旁勘察 | 腹部与后腿站稳，头部小幅左右探查，双触角不同步摆动 | 去掉原地转整圈和虚构绕圈位移 |
| 切割 | 稳住、调整嘴部、连续三次咬合、收住小块食物 | 前 15% 就位，中间 70% 咬合，最后 15% 收住；随实际切割进度播放 |
| 搬起食物 | 很轻的身体压低与恢复 | 拾取发生后约 0.35 秒 |
| 负重行走 | 更短的步幅、触角稍收、嘴边馒头随头轻动、较缓的转身 | 位移来自真实搬运速度，负重转向速度从 14 降到 9 rad/s |
| 偶遇 | 部分迎面相遇的空手蚂蚁短暂摆触角回应 | 23 像素内触发约 0.38 秒回应，每只至少间隔 7 秒，不强迫停下 |
| 受阻重探 | 小幅回看后再定向 | 随已有 recover/reorient 进度播放，避免连续陀螺转圈 |
| 入巢 | 保留朝回收站入口缩小、下沉和碎屑消散 | 送达计数仍发生在算法完成入巢时 |

偶遇只表示视觉回应，不模拟真实触角碰撞或改变路线；不会因为演出而虚增发现、切割或搬运进度。隐藏时停止绘制；恢复时清掉旧的视觉运动记录，避免把后台累计位移当作一大步。

## 体验自查

- 设计参考：小动物的先感知后行动，以及动画的预备、发力、收势；采用头部独立于稳定腹部的动作层次。
- 移动端检查：虽然产品用于 Windows 桌面，390×844、DPR 2 的渲染用例也通过；没有增加面板内容。
- 文案/样式复用：延续现有炭黑、暖色轮廓、馒头和信息素视觉。演出在桌面完成。
- 发现的问题：原四相步态偏跳、原地整圈勘察生硬、发现食物时缺少明确朝向、暂停后角度仍会追赶。
- 已修复：八相步态、独立头部动作、实际感知朝向、停顿和发力节奏、暂停稳定、碰面冷却；文件图标遮挡和隐藏画布释放保留。

## 验证

62 项算法与文件安全单测通过；手绘渲染、可见性、动作时间与暂停烟测通过。动作测试检查输入坐标不被演出修改、相遇不重复触发、切割有多个不同姿势、恢复后复用图集。

125% 缩放下，8×8 姿势图集为 589824 字节（约 0.56 MiB），比原图集增加 405504 字节（约 0.39 MiB）；36 只蚂蚁仍为每帧 36 次精灵绘制。这里只是动作图集大小，不代表整个 Electron 程序的内存。

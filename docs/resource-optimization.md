# 桌宠资源优化实测（2026-11-06）

本轮保持 36 只蚂蚁、原动画刷新策略、美术、探索与搬运算法。优化集中于减少重复绘制；算法、文件验证与回收逻辑没有修改。

## 已实施

- 蚂蚁层只清除上一帧的精灵与传送门接触区域，覆盖移除蚂蚁、空快照和缩放变化，避免每帧清空整个桌面。
- 地图层保留静态信息素背景，只更新食物、传送门及入巢区域；信息素换层、图标变化、窗口缩放等情况仍完整重绘。
- 缓存信息素外围光晕，亮芯继续使用原矢量绘制。纹理与矢量分批处理，减少绘制管线切换。缓存约 200 KiB，不改变算法中的信息素数值。
- 暂停并完成待处理信息素后停止请求动画帧。放置、移动、清除食物和切换显示仍会触发刷新；恢复运行后继续动画。隐藏但运行中的模拟继续推进。

## 对照结果

同机 Electron 31，1536×864 测试窗口、DPR 1.25、83 个模拟图标、36 只蚂蚁、相同随机种子，预运行 180 秒模拟时间。活跃阶段由 16ms 定时器驱动，采样 6 秒；窗口隐藏，因此这不是实际桌面帧率测试。文件均为模拟数据。

| 指标 | 优化前 | 优化后 |
|---|---:|---:|
| 采样帧数 | 366 | 374 |
| 地图与蚂蚁绘制调用平均耗时 | 2.46 ms/帧 | 2.29 ms/帧 |
| 渲染进程 CPU（Electron 指标） | 3.63% | 3.37% |
| GPU 进程 CPU（不是 GPU 利用率） | 7.60% | 7.13% |
| 全屏清除调用 | 744 | 19 |
| 累计清除逻辑像素面积 | 9.86 亿 | 0.89 亿 |
| Electron 各进程私有内存合计 | 235.43 MiB | 236.58 MiB |
| 暂停稳定后 3 秒动画帧 | 6 | 0 |

本次样本中，每帧绘制调用耗时与渲染/GPU 进程 CPU 合计约下降 7%。清除面积下降约 91% 是工作量计数，不能解读为整机资源下降 91%。短时 CPU 采样存在噪声，不承诺所有桌面场景相同比例；暂停阶段的旧版帧数受隐藏窗口节流影响。

内存没有实质下降。这里统计 Electron 进程私有内存，不等同于任务管理器所有列，也不包含完整原生探针与桌面环境。较大内存下降需要另外评估 Electron 容器和渲染架构，不能通过减少几次绘制保证实现。

原始数据：[优化前](../diagnostics/resources-baseline-final.json)、[优化后](../diagnostics/resources-optimized-final.json)。复测入口：`tests/resource-benchmark.js`，环境变量 `ANTS_BENCH_RENDERER` 指定渲染器目录、`ANTS_BENCH_LABEL` 指定结果名称；应顺序运行对照，避免争用资源。

## 效果与回归验证

- 62 项算法、文件安全单测通过。
- 保留绘制与完整重绘对照：蚂蚁像素差异为 0，涵盖入巢、移除蚂蚁及 DPR 切换；地图局部恢复最大通道差异为 1/255。
- 与冻结的旧信息素实现对照：在测试样本中，预乘透明度后的颜色最大差异约 2.13/255，平均约 0.044/255。外圈缓存不是数学上逐像素完全相同；亮芯保留原实现。
- 暂停后停止绘制、暂停时编辑、继续运行、隐藏模拟与返回桌面、真实窗口最小化恢复均通过。
- 手绘动作、图标背景替换及移动、传送门波纹、入回收站演出烟测通过。旧入巢测试改为读取实际蚂蚁画布层并换算 DPR，验证可见像素、切片显示以及送达前不计入回收字节。

没有采用的实验：合并全屏画布、强制 CPU 光栅化、同时缓存信息素亮芯。它们分别带来裁剪开销、内存增加或亮度差异，因此没有保留。
